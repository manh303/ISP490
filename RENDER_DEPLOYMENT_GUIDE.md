# 🚀 Hướng dẫn Deploy Backend lên Render

## 📋 Tổng quan

Hướng dẫn này sẽ giúp bạn deploy backend Vietnam E-commerce DSS lên Render với cấu hình production hoàn chỉnh.

## 🛠️ Chuẩn bị

### 1. Tài khoản cần thiết
- **GitHub account** (để kết nối repository)
- **Render account** (miễn phí tại [render.com](https://render.com))

### 2. Repository setup
- Push code lên GitHub repository
- Đảm bảo file `render.yaml` có trong root directory

## 📖 Các bước deploy

### Bước 1: Tạo Render account và kết nối GitHub

1. Đăng ký tài khoản tại [render.com](https://render.com)
2. Kết nối với GitHub account
3. Authorize Render để access repository của bạn

### Bước 2: Deploy từ render.yaml

1. **Vào Render Dashboard**
   - Click "New" → "Blueprint"
   - Chọn repository: `ecommerce-dss-project`
   - Render sẽ tự động detect file `render.yaml`

2. **Review services**
   ```yaml
   Services sẽ được tạo:
   ✅ ecommerce-dss-backend (Web Service)
   ✅ ecommerce-dss-db (PostgreSQL)
   ✅ ecommerce-dss-redis (Redis)
   ✅ ecommerce-dss-frontend (Static Site)
   ```

3. **Deploy Blueprint**
   - Click "Apply"
   - Render sẽ tự động tạo tất cả services

### Bước 3: Cấu hình Database

1. **Truy cập PostgreSQL Database**
   - Vào service `ecommerce-dss-db`
   - Copy connection string từ "Internal Database URL"

2. **Run migration script**
   ```bash
   # Connect to database using psql or any PostgreSQL client
   psql "your-postgres-connection-string"

   # Run the initialization script
   \\i backend/migrations/init_production.sql
   ```

3. **Verify database setup**
   ```sql
   -- Check schemas
   \\dn

   -- Check tables
   \\dt bronze.*
   \\dt silver.*
   \\dt gold.*
   \\dt dw_core.*
   ```

### Bước 4: Cấu hình Environment Variables

Vào backend service và thêm các environment variables:

#### Core Settings
```env
ENVIRONMENT=production
DEBUG=false
SECRET_KEY=your-super-secret-key-change-this
LOG_LEVEL=INFO
```

#### Database & Cache
```env
DATABASE_URL=${ecommerce-dss-db.DATABASE_URL}
REDIS_URL=${ecommerce-dss-redis.REDIS_URL}
```

#### JWT Authentication
```env
JWT_SECRET_KEY=your-jwt-secret-key-different-from-secret-key
JWT_ALGORITHM=HS256
JWT_EXPIRATION_HOURS=24
```

#### CORS & API
```env
CORS_ORIGINS=https://ecommerce-dss-frontend.onrender.com,http://localhost:3000
API_HOST=0.0.0.0
PORT=10000
```

#### Performance
```env
WORKERS=1
TIMEOUT=120
MAX_CONNECTIONS=100
POOL_SIZE=10
CACHE_TTL=300
```

### Bước 5: Test deployment

1. **Check service health**
   ```bash
   curl https://ecommerce-dss-backend.onrender.com/health
   ```

2. **Test API endpoints**
   ```bash
   # API status
   curl https://ecommerce-dss-backend.onrender.com/api/v1/status

   # Test authentication
   curl -X POST https://ecommerce-dss-backend.onrender.com/api/v1/auth/login \\
        -H "Content-Type: application/json" \\
        -d '{"username": "demo", "password": "demo123"}'

   # Test dashboard
   curl https://ecommerce-dss-backend.onrender.com/api/v1/analytics/dashboard
   ```

3. **Check Swagger UI**
   - Truy cập: `https://ecommerce-dss-backend.onrender.com/docs`

## 🚨 Security Checklist

### 1. Environment Variables
- [ ] `SECRET_KEY` - Unique, complex key
- [ ] `JWT_SECRET_KEY` - Different from SECRET_KEY
- [ ] Database credentials - Auto-generated by Render
- [ ] `DEBUG=false` in production

### 2. CORS Configuration
- [ ] Update `CORS_ORIGINS` with actual frontend domains
- [ ] Remove `*` from CORS origins
- [ ] Verify API endpoints are properly secured

### 3. Database Security
- [ ] Use connection pooling
- [ ] Enable SSL connections
- [ ] Regular backups (auto-enabled in Render)

## 🔄 CI/CD Setup

### 1. Auto-deploy từ GitHub
```yaml
# .github/workflows/deploy.yml
name: Deploy to Render
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Deploy to Render
        run: echo "Render auto-deploys from main branch"
```

### 2. Environment-specific deploys
- **Development**: Auto-deploy từ `develop` branch
- **Staging**: Manual deploy từ `staging` branch
- **Production**: Manual deploy từ `main` branch

## 🆘 Troubleshooting

### Common Issues

#### 1. Build failures
```bash
# Check build logs
render logs ecommerce-dss-backend --build

# Common fixes:
- Check requirements.txt dependencies
- Verify Python version compatibility
- Review file paths in buildCommand
```

#### 2. Database connection issues
```bash
# Test connection
psql $DATABASE_URL -c "SELECT 1;"

# Common fixes:
- Verify DATABASE_URL format
- Check VPC connectivity
- Review security group settings
```

#### 3. Memory/Performance issues
```bash
# Monitor resource usage
render metrics ecommerce-dss-backend

# Optimization options:
- Upgrade to paid plan (more RAM/CPU)
- Optimize database queries
- Enable caching
- Review worker count
```

#### 4. SSL/HTTPS issues
```bash
# Render auto-provides SSL certificates
# If issues persist:
- Check DNS configuration
- Verify domain settings
- Contact Render support
```
