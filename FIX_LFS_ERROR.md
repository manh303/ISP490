# Fix Git LFS Budget Error

## Problem
```
This repository exceeded its LFS budget
Error downloading data-pipeline/models/clustering_scaler.pkl
```

## Root Cause
Git LFS có giới hạn bandwidth/storage miễn phí. Các file model ML đang dùng LFS.

## Solution: Remove LFS Files

### Option 1: Remove model files from Git (Recommended)

```bash
# 1. Remove LFS tracked files
git rm data-pipeline/models/*.pkl
git rm data-pipeline/models/*.joblib
git rm data-pipeline/models/*.h5

# 2. Update .gitignore
echo "# ML Models" >> .gitignore
echo "data-pipeline/models/*.pkl" >> .gitignore
echo "data-pipeline/models/*.joblib" >> .gitignore
echo "data-pipeline/models/*.h5" >> .gitignore
echo "*.pkl" >> .gitignore
echo "*.joblib" >> .gitignore

# 3. Commit
git add .gitignore
git commit -m "Remove ML model files from Git LFS"

# 4. Push
git push origin manh303
```

### Option 2: Disable LFS for this repo

```bash
# 1. Remove .gitattributes LFS rules
git rm .gitattributes

# 2. Remove LFS files
git rm data-pipeline/models/*.pkl

# 3. Commit
git commit -m "Disable Git LFS"

# 4. Push
git push origin manh303
```

## Alternative: Store models elsewhere

### Option A: Download models at runtime
```python
# In your app startup
import requests
import os

MODEL_URL = "https://your-storage.com/models/clustering_scaler.pkl"
MODEL_PATH = "data-pipeline/models/clustering_scaler.pkl"

if not os.path.exists(MODEL_PATH):
    os.makedirs(os.path.dirname(MODEL_PATH), exist_ok=True)
    response = requests.get(MODEL_URL)
    with open(MODEL_PATH, 'wb') as f:
        f.write(response.content)
```
