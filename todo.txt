Toi uu /dss/reco/run cho bang ml.fact_product_recommendation (~2M record). Muc tieu: giam scan Postgres, them index, toi uu AI summarizer, va can nhac cache.

Flow hien tai:
- Endpoint `POST /reco/run` goi `service.run_product_recommendation_dss`.
- Service: (1) `_query_product_recommendations` (by_product/by_category). (2) `_calculate_reco_kpis`. (3) Build `dss_result_raw`. (4) Goi `ai_summarizer.summarize_with_ai(...)`. (5) Insert session -> return.
- O DB: ca hai ham con deu co CTE `product_metrics` scan toan bo `dwh.fact_product_daily`, roi join `ml.fact_product_recommendation + dim_product + dim_category`. Sau do moi goi AI qua network. Voi ~2M record + full scan fact + LLM call nen dang cham.

Toi uu DB (uu tien):
1) Giam full scan `fact_product_daily` trong `product_metrics`
- Cach A (nhanh): them filter ngay nhu price DSS.
```
WITH product_metrics AS (
  SELECT f.product_sk,
         AVG(f.avg_price) AS avg_price,
         SUM(f.total_review_count) AS total_orders
  FROM dwh.fact_product_daily f
  JOIN dwh.dim_date dd ON f.date_sk = dd.date_sk
  WHERE dd.date_value BETWEEN $1 AND $2  -- from_date, to_date (7-30 ngay gan nhat)
  GROUP BY f.product_sk
)
```
- Truyen `from_date`, `to_date` vao request (by_product & by_category).
- Cach B (neu muon overall): precompute bang/materialized view.
```
CREATE TABLE IF NOT EXISTS dwh.product_metrics_global AS
SELECT f.product_sk,
       AVG(f.avg_price) AS avg_price,
       SUM(f.total_review_count) AS total_orders
FROM dwh.fact_product_daily f
GROUP BY f.product_sk;

CREATE UNIQUE INDEX IF NOT EXISTS idx_product_metrics_global_pk
  ON dwh.product_metrics_global(product_sk);
```
- Trong SQL reco: bo CTE, `LEFT JOIN dwh.product_metrics_global pm_rec ON dp_rec.product_sk = pm_rec.product_sk`. Cap nhat bang nay hang ngay bang Airflow.

2) Index cho `ml.fact_product_recommendation`
```
CREATE INDEX IF NOT EXISTS idx_fact_product_reco_src_sim_rank
  ON ml.fact_product_recommendation (source_product_sk, similarity_score DESC, rank);

CREATE INDEX IF NOT EXISTS idx_fact_product_reco_rec_sim
  ON ml.fact_product_recommendation (recommended_product_sk, similarity_score DESC);
```
Giup loc theo source_product va sort similarity/rank nhanh hon.

3) Index cho `dwh.dim_product` & `dwh.fact_product_daily`
```
CREATE UNIQUE INDEX IF NOT EXISTS idx_dim_product_product_key ON dwh.dim_product(product_key);
CREATE INDEX IF NOT EXISTS idx_dim_product_category ON dwh.dim_product(category_sk);
CREATE INDEX IF NOT EXISTS idx_dim_product_platform_category
  ON dwh.dim_product(platform_sk, category_sk, product_sk);

CREATE INDEX IF NOT EXISTS idx_fact_product_daily_date_product
  ON dwh.fact_product_daily(date_sk, product_sk);
```

4) Tranh `SUBSTRING(product_key)` khi loc platform
- Dam bao `dim_product` co `platform_sk`, join them `dwh.dim_platform`:
```
JOIN dwh.dim_platform dpl ON dp_rec.platform_sk = dpl.platform_sk
SELECT dpl.platform_code AS platform, ...
```
- Filter platform: `dpl.platform_code = ANY($x)` thay vi `SUBSTRING(...)`. Index o buoc (3) ho tro.

5) Gioi han tham so yeu cau
- `top_k = min(request.get("top_k", 10), 50)`
- `min_similarity = max(request.get("min_similarity", 0.5), 0.6)` (de xuat 0.6-0.7).

Toi uu AI summarizer:
- Them flag `ai_mode` (full|fast) trong schema:
  - full: goi LLM neu `ai_summarizer.available`.
  - fast: dung `_get_fallback_response(...)` rule-based (khong goi LLM).
- Khi build prompt, chi gui top 10-20 recommendation vao table_data de giam token.

Caching `/dss/reco/run`:
- Cache ket qua `_query_product_recommendations` (hoac output cuoi) bang Redis ~1h theo key gom scope_mode + request JSON da sort.

Uu tien trien khai:
- Level 1 (bat buoc): filter ngay hoac precompute `product_metrics`, tao index `ml.fact_product_recommendation` + `dim_product` + `fact_product_daily`, gioi han `top_k`/`min_similarity`.
- Level 2 (nen lam): bo SUBSTRING, join `dim_platform`, them index `(platform_sk, category_sk, product_sk)`.
- Level 3 (toi uu p95): `ai_mode` fast/full + Redis cache.
