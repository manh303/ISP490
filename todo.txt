1. Nhóm “Tổng quan & kịch bản DSS”
1.1. Màn DSS Overview / Dashboard (/dss – DSSPage)

Mục đích:
Cho Analyst 1 màn tổng quan ecommerce + entry point để nhảy sang các phân tích sâu hơn (price, brand, trending, AI suggestions).

Layout gợi ý:

Header

Tiêu đề: E-commerce DSS Dashboard

Subtitle: “Tổng quan dữ liệu & điểm vào các kịch bản DSS”

Ở góc phải: Dropdown chọn role (Analyst) hoặc quick link “Go to DSS Scenarios”.

Thanh tab ngang:

Dashboard (default)

Price Analysis

Brand Analysis

Trending Products

AI Recommendations (hoặc AI Assistant)

Tab: Dashboard

Section 1 – Summary cards (4–6 card)

Total Products

Platforms Count

Average Price

Rated Products (số sản phẩm có review)

Có thể thêm: “Latest Crawl Date”, “ML Models Status (OK/Warn)”

Section 2 – Platform breakdown

Bảng hoặc bar chart: mỗi dòng 1 platform (Tiki, Lazada, Shopee)

total_products, avg_price, rated_products

Section 3 – Category snapshot

Bảng top N category theo:

total_products

avg_price

avg_rating

Section 4 – Quick links

3 card:

“Tối ưu giá” → dẫn tới /analyst/dss-scenarios với model price_prediction focus.

“Gợi ý sản phẩm” → product_recommendation.

“Cảm xúc review” → review_sentiment.

Tab: Price Analysis

Filter bar bên trên:

Date range

Platform multi-select

Category selector

Main content:

Chart: so sánh phân bố giá / median price theo category & platform.

Card “Products with biggest price gap vs prediction” (link sang DSSInput để chạy DSS chi tiết).

CTA: Button “Run Price Optimization DSS” → /analyst/dss-input/price_prediction.

Tab: Brand Analysis

Bảng: each row brand (Apple, Samsung, …)

avg_price, avg_rating, total_reviews, share of revenue.

Bar/line chart: market share theo brand.

Tab: Trending Products

Grid card:

Image (nếu có), product_name, platform, category

price, avg_rating, total_reviews

tag “🔥 trending” nếu growth > X%

CTA “Phân tích sâu sản phẩm này” → mở DSSInput với scope by_product.

Tab: AI Recommendations

Khu vực hiển thị mấy insight tổng hợp kiểu:

“Top 10 sản phẩm nên điều chỉnh giá”,

“Top 5 category có sentiment giảm”,…

Button dẫn tới từng DSS tương ứng.

1.2. Màn DSS Scenarios (kịch bản DSS) – /analyst/dss-scenarios (DSSScenarios)

Mục đích:
Giải thích rõ 3 model DSS (Price / Reco / Sentiment), mô tả use case + input cần, cho Analyst chọn kịch bản thay vì chọn “model kỹ thuật”.

Layout:

Header

Title: DSS Scenarios

Subtitle: “Chọn bài toán business bạn muốn giải quyết”

Danh sách scenario (3 card lớn)

Mỗi DSSScenario card (dữ liệu từ API):

Price Prediction (price_prediction)

Icon: 🔮 / TrendingUp

Title: “Tối ưu hóa giá bán”

Description: “Đề xuất giá tối ưu cho sản phẩm để tăng doanh thu/lợi nhuận”

Use cases:

Tăng doanh thu của top sản phẩm

Chuẩn bị giá cho campaign

So sánh giá với thị trường

Required inputs: from_date, to_date, platforms, categories, scope_mode, (optional product_keys)

Button:

“Run Scenario” → /analyst/dss-input/price_prediction

“View Previous Decisions” → /analyst/dss-decisions?scenario=price_prediction

Product Recommendation (product_recommendation)

Icon: 👥 / Users

Description: “Gợi ý sản phẩm bổ sung / cross-sell”

Use cases:

Đề xuất combo

Tối ưu giỏ hàng, tăng basket size

Required inputs: scope_mode, source_product_key, optional platforms, categories, top_k, min_similarity

Button “Run Scenario” → /analyst/dss-input/product_recommendation

Review Sentiment (review_sentiment)

Icon: 💬 / MessageSquare

Description: “Theo dõi cảm xúc khách hàng từ review”

Use cases:

Phát hiện khủng hoảng

Monitor chất lượng sản phẩm

Required inputs: from_date, to_date, platforms, categories, scope_mode, (optional product_key, min_reviews_per_product)

Button “Run Scenario” → /analyst/dss-input/review_sentiment

Panel bên phải / dưới

Khi click vào 1 scenario → hiển thị detail:

Mô tả, KPI chính, output fields, ví dụ action.

2. Nhóm “Chạy DSS” – Input & Results
2.1. Màn DSS Input – /analyst/dss-input/:modelId (DSSInput)

Mục đích:
Form để Analyst config một lần chạy DSS cho 1 model (price_prediction / product_recommendation / review_sentiment).

Header:

Breadcrumb: DSS → Scenarios → [Tên model] → Input

Title: ví dụ Tối ưu hoá giá (Price Prediction DSS)

Subtext: “Chọn phạm vi dữ liệu & tham số phân tích”

Layout 2 cột:

Cột trái – Thông tin model

Card giới thiệu model hiện tại:

Icon, name, description (từ models[modelId] trong code)

Danh sách “fields” bắt buộc cho model đó (đã có mảng fields trong code).

Panel nhỏ: “Gợi ý sử dụng”

Ví dụ price: “Chọn date range >= 7 ngày, ưu tiên category có doanh thu cao”.

Cột phải – Form input

Phần A – Filter chung (tuỳ model):

Date range (from_date, to_date)

DatePicker đôi, dùng icon lịch.

Default:

Price / Reco: 7–30 ngày gần nhất

Sentiment: 1–3 tháng gần nhất

Platform (platform_code)

Select (multi nếu bạn muốn), options: Tiki, Lazada, Shopee.

Category (category)

Category selector (combo box): dữ liệu từ getCategories().

Cho phép search theo tên.

Scope Mode (scope_mode)

Select:

by_category – phân tích toàn category

by_product – focus 1 sản phẩm

top_n – lấy N sản phẩm top theo doanh thu

Ghi chú ngắn dưới field.

Product Key (product_key) – chỉ hiện nếu:

modelId = product_recommendation và scope_mode = by_product

hoặc modelId = review_sentiment và scope_mode = by_product

Input text + hint: “VD: lazada_123456” (tạm, sau có thể chuyển thành search API).

Phần B – Tham số riêng cho từng model

Price Prediction

Group “Advanced Pricing Constraints”:

max_discount_pct (slider hoặc input %): “Giảm tối đa X% so với giá hiện tại”

min_margin_pct: “Biên lợi nhuận tối thiểu Y%”

min_confidence: “Ngưỡng confidence tối thiểu để chấp nhận”

min_price_change_pct: “Chỉ khuyến nghị giá nếu chênh lệch >= Z%”

Có thể default ẩn và có toggle “Hiển thị tuỳ chọn nâng cao”.

Product Recommendation

Field:

top_k: số gợi ý / sản phẩm (default 10)

min_similarity: từ 0–1

min_co_purchase_rate: từ 0–1

Review Sentiment

Field:

min_reviews_per_product: số review tối thiểu

sentiment_focus: radio:

All

Only Negative

Only Positive

Footer form:

Button “Chạy DSS” (primary)

Button “Huỷ / Quay lại Scenarios”

Loading spinner khi submit.

Sau khi submit thành công:

Điều hướng tới /analyst/dss-results/:modelId

navigate('/analyst/dss-results/price_prediction', { state: { inputData, dssResults } })

2.2. Màn DSS Results – /analyst/dss-results/:modelId (DSSResults)

Mục đích:
Hiển thị kết quả phân tích + AI summary & recommended actions cho lần chạy DSS đó.

Header:

Breadcrumb: DSS → Scenarios → [Tên model] → Results

Hiển thị tóm tắt input đã dùng:

Date range, platforms, categories, scope, top_n…

Layout tổng: 2 phần

Phần trên – Overview & AI Summary

Model summary header

Icon tương ứng (Price / Reco / Sentiment)

Tên model

Tag: “Session #123 / Created at 2025-12-05 22:57 / AI Model: gemini-pro / gpt-4o-mini…”

KPI cards (tuỳ model)

Price Prediction:

Số sản phẩm phân tích (num_products)

Số sản phẩm có khuyến nghị (num_with_recommendation)

Current Revenue (tổng)

Projected Revenue (tổng)

Expected Uplift %

Avg Confidence

Product Recommendation:

Tổng số sản phẩm nguồn / session

Tổng số recommendations (rows)

Avg similarity

Avg co_purchase_rate

Review Sentiment:

Tổng số sản phẩm được phân tích

Tổng review

Avg positive_pct, avg_negative_pct

sản phẩm “critical negative”

Avg rating

AI Summary & Risks

Box “AI Insights” – list bullet 3–5 insight (từ ai_summary_insights[]).

Box “AI Recommended Actions (High level)” – list 3–5 action, có tag Level:

[PRICE], [RECO], [CS], [MARKETING]…

Nếu có date_adjustment_info → panel nhỏ: “We adjusted your date range to … because …”.

Phần dưới – Detailed Table + AI Actions

Tuỳ model, render khác nhau:

a) Price Prediction

Table: Price Recommendations

Columns:

Product

Platform

Category

Current Price

Predicted Price

Recommended Price (nếu có guardrail)

Price change % (badge màu xanh/đỏ)

Current Orders

Current Revenue

Projected Revenue

Expected Revenue Uplift %

Confidence %

Sorting:

Default sort theo expected_revenue_change_pct * current_revenue desc.

Pagination.

Action panel (phía bên phải hoặc dưới)

Danh sách ai_recommended_actions[] chi tiết, mỗi item:

Title

Description (nêu rõ sản phẩm hoặc nhóm sản phẩm)

Tag priority: HIGH / MEDIUM / LOW

Optional: Impact, Effort.

Button “Create Decision from this” → mở DSSDecisionCreatePage với prefill dữ liệu.

b) Product Recommendation

Table: Recommendations

Mỗi dòng:

Source Product

Recommended Product

Platform

Category

similarity_score

co_purchase_count

co_purchase_rate

avg_bundle_revenue

Filter:

Min similarity slider

Min co_purchase_rate slider

Filter theo source_product_key.

AI actions:

Ví dụ: “Tạo combo A + B trên Tiki với discount 10%”, “Đề xuất nhóm sản phẩm này vào widget ‘Frequently Bought Together’…”.

c) Review Sentiment

Table: Product Sentiment

Columns:

Product, Platform, Category

total_reviews

positive_pct, neutral_pct, negative_pct

avg_rating

sample_negative_reviews (show icon + mở modal xem chi tiết)

sample_positive_reviews

top_positive_reasons / top_negative_reasons (list tag)

Filter:

Chỉ show sản phẩm negative_pct >= X khi chọn “critical focus”.

Charts phụ:

Pie chart phân bố sentiment toàn scope.

Bar chart top sản phẩm negative_pct cao.

AI actions:

“Trả lời toàn bộ review negative trong 24h cho 10 sản phẩm top risk”

“Mở investigation về lỗi QC cho nhóm sản phẩm X”…

3. Nhóm “Decision & Action log”
3.1. Màn Danh sách Decision DSS – /analyst/dss-decisions (DSSDecisionsPage)

Mục đích:
Quản lý lịch sử “quyết định đã chốt” dựa trên DSS (khác với kết quả raw AI, đây là quyết định business).

Header:

Title: DSS Decisions

Button: “+ Create Decision” → /analyst/dss-decisions/create

Filters:

Scenario select (scenario_key):

All, Price Prediction, Product Recommendation, Review Sentiment

Status:

DRAFT, APPROVED, IN_PROGRESS, DONE, CANCELLED

Date range: created_at

Search box theo title / product_name.

Table columns:

Decision ID

Title

Scenario (icon + text)

Status badge

Owner (user who created)

Created at, Last updated

#Actions in decision

Link “View details”

Pagination (page/pageSize).

3.2. Màn Decision Detail – /analyst/dss-decisions/:decisionId (DSSDecisionDetailPage)

Mục đích:
Xem chi tiết 1 quyết định: bối cảnh, kết quả DSS gốc, list action chi tiết, trạng thái thực thi.

Header:

Back link → /analyst/dss-decisions

Title = decision.title

Tag:

Scenario: Price / Reco / Sentiment

Status (badge màu)

Section 1 – Meta

Decision ID

Scenario key

Owner, created_at, updated_at

Link tới DSS Session (nếu có analysis_session_id) – “View original DSS Run”.

Section 2 – Context & Summary

description (markdown view nếu bạn muốn).

kpi_summary hiển thị dạng key-value / grid:

For price: current_revenue, projected_revenue, uplift…

For sentiment: total_reviews, avg_negative_pct…

Section 3 – AI Insights & Actions (read-only)

2 panel:

AI summary insights (những gì AI nói)

AI recommended_actions (nguyên văn, để tham chiếu)

Section 4 – Action items

Bảng action:

Action ID

Title

Action type (pricing, marketing, cs, etc)

Owner (phụ trách)

Due date

Status (NOT_STARTED, IN_PROGRESS, DONE)

Impact / Priority (optional)

Link tới ticket ngoài (Jira, Trello…) nếu có field external_link.

3.3. Màn Tạo mới Decision – /analyst/dss-decisions/create (DSSDecisionCreatePage)

Mục đích:
Cho Analyst “chốt” một quyết định/plan từ kết quả DSS + AI actions.

Form fields:

scenario_key (Select)

Price / Reco / Sentiment

title (Input, required)

description (Textarea)

Có thể paste lại kết quả, insight quan trọng.

status (Select)

DRAFT, APPROVED, IN_PROGRESS, DONE

Action list (dynamic)

Nút “Add action” mở form nhỏ cho từng DSSActionItem:

title (required)

description

type (pricing, marketing, cs…)

owner (text hoặc select)

due_date

priority (HIGH/MEDIUM/LOW)

Có thể thêm nhiều action, list bên dưới cho phép edit/delete.

Footer:

Button “Save Decision” (lưu qua saveDSSDecision)

Button “Cancel”

Nếu vào từ DSSResults với state prefill, bạn có thể:

Prefill scenario_key + description + list actions từ ai_recommended_actions.

4. Màn DSS System Health – /analyst/dss-health (DSSHealth)

Mục đích:
Giúp Analyst (và cả Admin/DE/ML) xem DSS có đủ data & ML model chạy ổn chưa trước khi tin kết quả.

Header:

Title: DSS System Health

Subtitle: “Monitor data pipeline, ML model status & DSS API health”

Button “Refresh Now” (spin icon khi đang refresh).

Sections:

Overall Status

Big indicator: ✅ Healthy / ⚠️ Degraded / ❌ Failing

Dựa trên aggregate từ API getDSSHealth, getDataStatus.

Data Status (by schema / table)

Cards hoặc bảng:

Raw Layer: last_updated, record_count, status

DWH Layer: fact_product_daily, dim_product, dim_category,… mỗi cái:

last_loaded_at, row_count, status icon.

ML Model Status

List models:

Price model: version, trained_at, MAE/RMSE, status

Reco model: version, last retrain, #products covered

Sentiment model: version, accuracy, F1.

Maybe link “Retrain logs” nếu sau này có.

DSS API Status

Last run time for:

/dss/price/run

/dss/reco/run

/dss/review/run

Average response time, last error (nếu có).

Recent Alerts

List log các warning: category mapping OTHER > 15%, missing predictions cho N sản phẩm, ML model stale > 30 days…
