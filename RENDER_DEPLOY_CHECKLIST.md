## Common Issues & Solutions

### Issue 1: Module Not Found
**Solution:** Check imports use `app.` prefix
```bash
cd backend
grep -r "from services\." app/ --include="*.py"
grep -r "from utils\." app/ --include="*.py"
```

### Issue 2: Git LFS Error
**Solution:** Already fixed - models removed from Git
```bash
git lfs ls-files  # Should show nothing
```

### Issue 3: Database Connection Failed
**Solution:** Check DATABASE_URL environment variable
```bash
# In Render dashboard, verify:
DATABASE_URL=postgresql://...
```

### Issue 4: Port Binding Error
**Solution:** Use $PORT from Render
```bash
# Start command should have:
--port $PORT
```
